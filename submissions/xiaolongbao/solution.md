# 小笼包 题解

## 1. 题意简述

有 $n$ 种蒸笼，第 $i$ 种能装 $A_i$ 个小笼包，每种蒸笼都可以使用任意多次。问是否存在无限多个正整数 $x$，使得 $x$ 无法表示成若干个 $A_i$ 之和；存在输出 `YES`，否则输出 `NO`。

## 2. 解题思路

### 2.1 能凑出的数都是最大公因数的倍数

设

$$
g=\gcd(A_1,A_2,\ldots,A_n).
$$

如果用了第 $i$ 种蒸笼 $c_i$ 次，那么凑出的小笼包数量是

$$
c_1A_1+c_2A_2+\cdots+c_nA_n.
$$

因为每个 $A_i$ 都是 $g$ 的倍数，所以任何能凑出的 $x$ 一定也是 $g$ 的倍数。

如果 $g>1$，那么所有不是 $g$ 的倍数的正整数都凑不出来。这样的正整数有无穷多个，所以答案是 `YES`。

### 2.2 最大公因数为 1 时只有有限个失败

如果 $g=1$，结论是：只有有限多个正整数不能表示成这些 $A_i$ 的非负整数倍之和，超过某个界限之后全部都能凑出。

这是凑数问题的经典结论。直观地说，把所有整数按某个 $A_i$ 取余数；因为所有数的最大公因数为 $1$，可以构造出每个余数的最小可表示数。之后不断加上这个 $A_i$，就能表示该余数下所有更大的数。余数只有有限个，所以凑不出的数也只有有限个。

因此：

- $g>1$：无限多个数凑不出，输出 `YES`；
- $g=1$：只有有限多个数凑不出，输出 `NO`。

当 $n=1$ 时，$g=A_1$。若 $A_1=1$，所有正整数都能凑出；若 $A_1>1$，只有它的倍数能凑出。上面的判断同样成立。

### 2.3 算法与复杂度

只需要读入所有 $A_i$，用欧几里得算法依次求最大公因数：

$$
g \leftarrow \gcd(g,A_i).
$$

初始令 $g=0$，因为 $\gcd(0,a)=a$。

每次求 gcd 的时间是 $O(\log \max A_i)$，总时间复杂度 $O(n\log \max A_i)$，空间复杂度 $O(1)$。

## 3. 常见易错点

- 把答案写反：$g>1$ 时应输出 `YES`，$g=1$ 时应输出 `NO`。
- 只检查所有数是否都是偶数，漏掉公因数为 $3,5$ 等其他情况。
- 只求前两个数的 gcd，忘记后面还有蒸笼。
- 用最小容量代替最大公因数。
- 初始把 $g$ 设成 $1$，导致结果永远是 `NO`。
- 用反复减法求 gcd，遇到 $1$ 和 $10^9$ 这样的数据会超时。
- 忘记处理 $n=1$ 的情况。
- 所有题目均不强求在最后一行输出后换行。

## 4. 参考代码与语法精讲

### 4.1 C++ 参考代码

```cpp
#include<bits/stdc++.h>
using namespace std;

long long gcdEuclid(long long a, long long b)
{
    while (b != 0)
    {
        long long r = a % b;
        a = b;
        b = r;
    }
    return a;
}

int main()
{
    int n;
    cin >> n;
    long long g = 0;
    for (int i = 0; i < n; i++)
    {
        long long a;
        cin >> a;
        g = gcdEuclid(g, a);
    }

    if (g > 1)
    {
        cout << "YES" << endl;
    }
    else
    {
        cout << "NO" << endl;
    }
    return 0;
}
```

#### C++ 语法细节讲解

- `long long` 用来保存容量和最大公因数。虽然 $A_i \le 10^9$ 用 `int` 也能存下，但 `long long` 可以避免中间计算溢出。
- `gcdEuclid` 使用辗转相除法：`a % b` 得到余数，然后令 `a = b`、`b = r`，直到 `b` 变成 $0$。此时 `a` 就是最大公因数。
- `g` 初始为 $0$，因为 $\gcd(0,a)=a$。第一次读入时，`gcdEuclid(0, a)` 会返回 $a$。
- 每读入一个 $A_i$ 就立即更新 `g`，不需要把所有数存进数组，空间复杂度是 $O(1)$。
- 最后只需要判断 `g > 1`，不需要真的去枚举哪些 $x$ 凑不出。

### 4.2 Python 参考代码

```python
import math

n = int(input())
a = list(map(int, input().split()))

g = 0
for x in a:
    g = math.gcd(g, x)

if g > 1:
    print("YES")
else:
    print("NO")
```

#### Python 语法细节讲解

- `import math` 导入数学库，`math.gcd` 可以直接求最大公因数。
- `list(map(int, input().split()))` 把第二行的字符串按空格切开，再全部转成整数，得到列表 `a`。
- `g = 0` 是初始值，`math.gcd(0, x)` 会返回 `x`，所以第一次循环等价于把 `g` 设成第一个容量。
- `g = math.gcd(g, x)` 依次把当前最大公因数和下一个容量合并，最终得到所有容量的最大公因数。
- `print("YES")` 和 `print("NO")` 会自动换行，输出格式符合要求。
