# 斯卡雷特警察巡逻贫民区24时

### 题面描述

“以《斯卡雷特警察侮辱罪》现行犯逮捕！”

贫民区出现了奇怪的 Funky 舞步！贫民区是一个 $n$ 行 $m$ 列的智慧冰精网格，但其中存在 $k$ 个邪恶冰精。每一秒，每个邪恶冰精都会把它上下左右相邻的智慧冰精变成邪恶冰精；刚被感染的冰精从下一秒开始也会继续感染别人。邪恶冰精不会移动，也不会变回智慧冰精。

斯卡雷特警察在异变开始的同时就发现了情况，并立刻出发。为了保证能以现行犯逮捕，她到达贫民区时，贫民区里必须仍然存在智慧冰精。请你告诉她，她最晚可以在第几秒到达。

形象地说：如果第 $p$ 秒结束时贫民区里所有智慧冰精都变成了邪恶冰精，那么她最晚必须在第 $p-1$ 秒到达。保证初始至少有一个智慧冰精。

### 输入描述

第一行三个整数 $n,m,k$（$1 \le n,m \le 1000$，$1 \le k < n \times m$），分别表示网格的行数、列数和初始邪恶冰精的数量。

接下来 $n$ 行，每行一个长度为 $m$ 的字符串，仅由字符 `.` 和 `X` 组成。`.` 表示智慧冰精，`X` 表示邪恶冰精。保证 `X` 的数量恰好为 $k$。

### 输出描述

输出一行一个整数，表示斯卡雷特警察最晚可以到达的秒数。

### 样例

**【样例 1】**

**样例输入：**

~~~text
3 3 1
X..
...
...
~~~

**样例输出：**

~~~text
3
~~~

#### 样例解释 #1：

唯一的邪恶冰精在左上角，离它最远的格子是右下角，需要 $4$ 秒才会被感染。第 $4$ 秒结束时所有智慧冰精都变成邪恶冰精，所以警察最晚要在第 $3$ 秒到达。

**【样例 2】**

**样例输入：**

~~~text
1 5 1
X....
~~~

**样例输出：**

~~~text
3
~~~

#### 样例解释 #2：

邪恶冰精在第 $1$ 秒感染第 $2$ 格，第 $2$ 秒感染第 $3$ 格，第 $3$ 秒感染第 $4$ 格，第 $4$ 秒感染第 $5$ 格。因此最晚要在第 $3$ 秒到达。

**【样例 3】**

**样例输入：**

~~~text
3 3 2
X..
...
..X
~~~

**样例输出：**

~~~text
1
~~~

#### 样例解释 #3：

两个邪恶冰精同时向外传播，最远的格子到最近邪恶冰精的距离是 $2$，所以第 $2$ 秒全部被感染，警察最晚在第 $1$ 秒到达。只从其中一个邪恶冰精出发计算会得到错误答案。

**【样例 4】**

**样例输入：**

~~~text
1 4 2
X..X
~~~

**样例输出：**

~~~text
0
~~~

#### 样例解释 #4：

中间两个智慧冰精在第 $1$ 秒同时被感染，第 $1$ 秒结束时贫民区已经没有智慧冰精，所以警察必须在第 $0$ 秒，也就是异变刚开始时到达。

### 提示

- $1 \le n,m \le 1000$，$1 \le k < n \times m$，时间限制 $1$ 秒，空间限制 $256$ MB。
- 所有冰精都按上下左右四个方向传播，没有障碍。
- 答案可能为 $0$，表示警察必须在异变开始的瞬间到达。
- 输出末尾有没有换行都算正确。
