# 舞神之路

### 题面描述

小 Satori 上大学后遇到了一位卖卡的学长。深入交流后，学长邀请他加入一个神秘群聊。他发现群里的人都在讨论一款叫做《舞萌 DX》的街机音游。后来，在一次和老玩家们的团建活动中，大家热情邀请他试玩这款游戏；不久，小 Satori 就迷上了它。

小 Satori 的 Rating 从 $0$ 开始。接下来他依次获得了 $n$ 条成绩记录，请你计算每获得一条成绩后，他当前的 Rating。

《舞萌 DX》的 Rating 由 B50 总分决定，而 B50 由两部分组成：

- **旧版本 B35**：所有旧版本谱面的历史最高单曲积分中，最高的 $35$ 条；
- **新版本 B15**：所有当前版本谱面的历史最高单曲积分中，最高的 $15$ 条。

B50 总分就是这两部分之和。谱面不足 $35$ 个或 $15$ 个时，有几个就取几个。

一条成绩的评级与系数的对应关系如下：

| 评级 | 系数 |
|:---:|---:|
| `SSS+` | $22.4$ |
| `SSS` | $21.6$ |
| `SS+` | $21.1$ |
| `SS` | $20.8$ |
| `S+` | $20.3$ |
| `S` | $20.0$ |
| `AAA` | $16.8$ |
| `AA` | $15.2$ |
| `A` | $13.6$ |
| `BBB` | $12.0$ |
| `BB` | $11.2$ |
| `B` | $9.6$ |
| `C` | $8.0$ |
| `D` | $6.4$ |

若一条成绩的谱面定数为 $\ell$，评级系数为 $c$，则它的单曲积分为

$$
s=\left\lfloor \ell \times c \right\rfloor.
$$

每条成绩还带有一个谱面编号 $id$。同一个谱面可以被反复游玩，但计算 B50 时，每个谱面只能贡献一条成绩，并且只保留这个谱面历史上最高的单曲积分。

输入会依次给出 $n$ 条成绩记录。每条记录都有版本编号：$0$ 表示旧版本，$1$ 表示当前版本。记录按输入顺序加入。

请在每读入一条成绩后，输出这一刻的 B50 总分。

### 输入描述

第一行一个正整数 $n$（$1 \le n \le 2\times 10^5$），表示成绩记录的数量。

接下来 $n$ 行，每行依次为一个实数 $\ell$、一个字符串 $r$、一个整数 $v$ 和一个整数 $id$，用单个空格分隔：

- $1.0 \le \ell \le 15.0$，且恰好有一位小数；
- $r$ 是上表中的一种评级；
- $v\in\{0,1\}$，其中 $0$ 表示旧版本，$1$ 表示当前版本；
- $1 \le id \le 10^9$，表示谱面编号。

保证同一个 $id$ 在所有记录中的 $\ell$ 和 $v$ 完全相同；只有评级 $r$ 可以随每次游玩而变化。

### 输出描述

输出 $n$ 行，每行一个整数。第 $i$ 行表示读完前 $i$ 条成绩后的 B50 总分。

### 样例

**【样例 1】**

**样例输入：**

~~~text
5
13.0 S 0 101
12.5 SSS 1 202
12.9 SS 0 303
13.0 SSS+ 0 101
12.9 A 0 303
~~~

**样例输出：**

~~~text
260
530
798
829
829
~~~

#### 样例解释 #1：

第一条成绩的单曲积分为 $\lfloor 13.0\times 20.0\rfloor=260$，旧版本只有这一条，所以总分是 $260$。

第二条成绩的单曲积分为 $\lfloor 12.5\times 21.6\rfloor=270$。此时取旧版本的最高 $1$ 条与新版本的最高 $1$ 条，总分是 $260+270=530$。

第三条成绩的单曲积分为 $\lfloor 12.9\times 20.8\rfloor=268$。它与第一条成绩同为旧版本，因此旧版本保留 $260$ 和 $268$，总分是 $260+268+270=798$。

第四条成绩再次游玩了谱面 $101$，单曲积分为 $\lfloor 13.0\times 22.4\rfloor=291$。它高于旧成绩 $260$，所以用 $291$ 替换 $260$，总分变为 $291+268+270=829$。

第五条成绩再次游玩了谱面 $303$，单曲积分为 $\lfloor 12.9\times 13.6\rfloor=175$，低于该谱面已有的 $268$，因此 B50 不变，仍然是 $829$。

**【样例 2】**

**样例输入：**

~~~text
4
13.1 D 1 1
13.1 S+ 1 1
13.1 S+ 1 2
13.1 SSS+ 1 1
~~~

**样例输出：**

~~~text
83
265
530
558
~~~

#### 样例解释 #2：

第一条成绩的谱面 $1$ 得到 $\lfloor 13.1\times 6.4\rfloor=83$ 分。第二条再次游玩谱面 $1$，成绩提高到 $265$，所以用 $265$ 替换 $83$。

第三条游玩了不同的谱面 $2$，也得到 $265$ 分，此时总分是 $265+265=530$。

第四条把谱面 $1$ 提高到 $\lfloor 13.1\times 22.4\rfloor=293$ 分，总分变为 $293+265=558$。

### 提示

- 所有谱面定数只差 $0.1$，但乘上系数后可能出现小数。题目规定的是**向下取整**，不能四舍五入。
- 同一个谱面的多次成绩只保留最高单曲积分；较低成绩不能改变榜单。
- 最多只保留旧版本 $35$ 条和新版本 $15$ 条，不需要保存所有历史成绩。
- B50 总分最大不超过 $50\times 15.0\times 22.4=16800$，但输入可能很长，需要每次高效地更新谱面最高分和两个小榜单。
- 输出末尾有没有换行都算正确。
