# 冰之勇者记1

### 题面描述

公主被梦魇巫女抓走了！冰之勇者决定立刻启程寻找公主。

在勇者眼中，世界是一个 $2 \times n$ 的迷宫。勇者初始站在 $(1,1)$，公主被关在 $(2,n)$。迷宫中 `0` 表示可以通行的道路，`1` 表示无法通过的障碍。勇者每次可以向上、下、左、右移动一格，但不能走出迷宫，也不能走进障碍。

作为兔子列车的列车长，请你告诉这位笨蛋勇者：她能否成功到达公主所在的位置？

### 输入描述

第一行一个整数 $n$（$1 \le n \le 10^5$）。

接下来两行，每行一个长度为 $n$ 的字符串，仅由字符 `0` 和 `1` 组成，分别表示迷宫的第一行和第二行。

保证 $(1,1)$ 与 $(2,n)$ 所在位置均为 `0`。

### 输出描述

如果勇者能够到达公主的位置，输出 `YES`；否则输出 `NO`。

### 样例

**【样例 1】**

**样例输入：**

~~~text
3
000
000
~~~

**样例输出：**

~~~text
YES
~~~

#### 样例解释 #1：

勇者沿着第一行一直向右走到 $(1,3)$，再向下走一格，就到达了公主所在的 $(2,3)$。

**【样例 2】**

**样例输入：**

~~~text
3
010
010
~~~

**样例输出：**

~~~text
NO
~~~

#### 样例解释 #2：

第二列的上下两个格子都是障碍，勇者无法从第一列走到第三列，因此无法到达公主身边。

**【样例 3】**

**样例输入：**

~~~text
6
001000
000010
~~~

**样例输出：**

~~~text
YES
~~~

#### 样例解释 #3：

勇者可以先从 $(1,1)$ 向下走到第二行，沿第二行走到第 $4$ 列，再向上回到第一行，走到第 $6$ 列后向下到达 $(2,6)$。这条路线换了不止一次行，说明只尝试“换一次行”是不够的。

### 提示

- $1 \le n \le 10^5$，时间限制 $1$ 秒，空间限制 $256$ MB。
- 勇者可以向四个方向移动，不只能向右走。
- 起点 $(1,1)$ 和终点 $(2,n)$ 保证是 `0`。
- 输出末尾有没有换行都算正确。
